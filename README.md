# Роман Карелин — рекрутинг для растущих команд

Одностраничный адаптивный сайт частного рекрутера. Стартовая специализация — подбор сотрудников для кафе, ресторанов и других проектов сферы гостеприимства.

## Локальный запуск

```bash
npm install
npm run dev
```

## Production-сборка

```bash
npm run build
```

Готовые файлы появятся в папке `dist`.

## Публикация

GitHub Actions автоматически собирает и публикует сайт через GitHub Pages после каждого обновления ветки `main`.

Перед окончательной публикацией необходимо добавить актуальные телефон, Telegram или email в контактный блок.
